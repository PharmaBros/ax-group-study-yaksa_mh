# 0_수집분석 — 미리 모아 둔 게시물과 분석

앤서니 팀이 명훈약사(@yaksa_mh) 공개 게시물을 모으고 **사실만** 분석한 자료다(게시물 그림, 캡션 통계, 그림 크기·색 실측, 글자 크기·여백 실측, 게시물 종류 판정). 부품 후보·대표 편 목록·디자인 설계 초안처럼 우리가 판단한 문서는 넣지 않았다 — 그 판단은 이 묶음의 클로드가 `1_공통설계서/설계하기.md`대로 새로 한다. 약사님이 게시물을 다시 모으지 않아도 되게 넣었다. **이 폴더의 파일은 원본이므로 고치지 않는다**(잘라 쓸 때는 복사해서 쓴다).

- 모은 날: **2026-11-03**(게시물 목록·캡션·좋아요·슬라이드 그림 — 브라우저로 공개 게시물만). 그 뒤에 올라온 게시물은 없다.
- 공개 카드뉴스(캐러셀) 슬라이드와 캡션만 있다. 릴스 영상·스토리·개인 게시물·따로 받은 본인 사진은 없다.
- 게시물 목록은 계정 전체 493개 중 최근 84개다.

## 편 폴더 이름 규칙

`게시물/<게시 날짜>_<아이디>/`
- 게시 날짜 = 한국 날짜(`YYYY-MM-DD`). 아이디 = 인스타 주소 `instagram.com/p/<아이디>/`의 그 글자.
- 안에 `1.jpg, 2.jpg …` = 받은 장 순서.
- `출처.json` = 주소·게시일·**`종류`**(분류.md와 같다)·장 수·인스타 장 수·동영상 장 수·받은 날·받은 방법·원본 해상도. `원본해상도`는 첫 장 기준이라 다른 장 크기와 다를 수 있다 — 장 크기는 그림을 열어 본다.
- 동영상 장·빠진 장은 없다(19편 모두 인스타 장 수와 받은 장 수가 같다).
- **가린 곳이 있다**: 본인 실명·생년월일·이메일이 보이던 검사지 장(DdZLyaHkpxS 6·7)과, 다른 약사님 브랜드 이름 글자(DfO658aEnB3 1·2, DdPCkuIErgI 3·4)는 이 묶음 사본에서 흐리게 가렸다. 편마다 `출처.json`의 `가린 곳`에 적었다. 가린 자리는 재지 않는다.
- `글.md`(장별 글을 받아 적은 것)는 `2026-10-12_DeaOxV-kiwX`에만 있다. 다른 장의 글은 그림을 열어 읽는다.
- 그림 크기·비율은 편별 표(`3_작업안내/명훈약사_작업안내.md` 1장)에 있다. 쓰면 안 되는 장은 같은 문서 2장.
- 종류는 `분류.md`가 기준이다(`출처.json`의 `종류`와 같다).

## 분석 문서 속 옛 경로 읽는 법

분석 문서는 우리 쪽 보관 폴더 이름으로 경로를 적었다. 이 묶음에서는 아래처럼 읽는다.

| 문서에 적힌 경로 | 이 묶음 안 자리 |
|---|---|
| `01/게시물목록.json`·`01_수집_인스타게시물/…`·`01/프로필.md` | `0_수집분석/게시물목록.json`·`프로필.md` |
| `02/슬라이드/<편>/`·`02_대표게시물_슬라이드/슬라이드/<편>/` | `0_수집분석/게시물/<편>/` |
| `02/분류.md` | `0_수집분석/분류.md` |
| `03_분석_계정특징/2026-11-03_1단계_실측.md` 등(`2026-11-03_` 머리) | `0_수집분석/1단계_실측.md`·`캡션통계.md`·`슬라이드실측.md` |
| 계정별메모·커스텀 설계서·정보형 모양표(우리가 쓴 설계 문서) | 묶음에 없음 — 이번에 약사님 쪽에서 새로 만든다(`7_결과/설계/`·`2_커스텀설계서/`) |
| `설계서/공통/작업_설계서.md`·`도구/…`(수집검증·캡션통계 도구 등)·`git-docs/…` | 묶음에 없음(우리 쪽 작업 문서·도구) — 필요 없다 |
| `한눈에보기/`, `_이전` 같은 옛 판, 검수 기록(`04_설계서검토/…`), `05_동의와설정/…`, `수집검증`, `릴스/` 커버 | 묶음에 없음(넣지 않음) |
| 우리가 만든 디자인 시스템 화면·부품 견본·그림 조각·완성 캐러셀 | 묶음에 없음 — 이번에 약사님 쪽에서 새로 만든다 |

- 문서에 나오는 `계정A`~`계정G`는 다른 약사님 계정 이름을 가린 것이다(명훈 = 이 계정 자신이라 이름 그대로). "사용자"·"앤서니"·"제이"는 그룹스터디 진행자다.
- 분석 문서의 숫자(편 수·장 수)는 그 문서를 쓴 때 기준이라 서로 다를 수 있다(예: 슬라이드실측은 19편 기준).
- 캡션통계·슬라이드실측의 `[도구]` 칸 안내, "대표 hex" 같은 말은 우리 쪽 도구가 쓴 말이다. "대표 hex"는 32단위로 뭉친 색 값이라는 뜻이고 대표 편과는 상관없다.
